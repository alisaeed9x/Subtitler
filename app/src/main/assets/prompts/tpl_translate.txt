فيما يلي مجموعة تعليمات مكتوبة بالعربية موجهة لنموذج ذكاء اصطناعي يقوم بمهمة ترجمة صوتية. المطلوب: ترجم هذه التعليمات بالكامل إلى اللغة "§LANG§" بدقة واحترافية، بحيث يفهمها نموذج ذكاء اصطناعي ناطق بلغة "§LANG§" بنفس الدقة والوضوح تماماً.

قواعد صارمة يجب اتباعها أثناء الترجمة:
1. لا تترجم أي نص داخل علامتي اقتباس مزدوجتين متبوعة بنقطتين رأسيتين مثل "translated": أو "gender": أو "start": — هذه أسماء حقول JSON تقنية ثابتة، اتركها بالإنجليزية تماماً كما هي بدون أي تغيير.
2. لا تترجم القيم النصية الثابتة داخل علامات اقتباس التي تمثل قيم برمجية مثل "male" أو "female" أو "plural" أو "none" أو "neutral" أو "shout" أو "true" أو "false" — اتركها بالإنجليزية كما هي بالضبط.
3. حافظ على كل الرموز الخاصة كما هي بدون تغيير: 🔴 ✅ 🌉 🗣️ 🌋 ═ — وأي رموز تعبيرية أخرى، وحافظ على نفس أسطر الفصل والتنسيق العام (فواصل الأسطر، الفقرات، الترقيم).
4. حافظ على كل النصوص اليابانية/الكورية/الصينية الأصلية الموجودة كأمثلة (مثل 僕 أو 오빠 أو 哥哥) كما هي بدون أي تعديل، وترجم فقط الشرح العربي المحيط بها.
5. المحتوى تعليمات تقنية دقيقة لمهمة ترجمة — ترجمها بأمانة الجملة الأصلية، دون حذف أو تلخيص أو إضافة أي شيء، فهذه القواعد كلها ضرورية وتفصيلية عمداً.
6. أرجع النص المُترجم فقط، بدون أي مقدمة أو شرح أو تعليق منك، وبدون علامات markdown.
