# Subtitler v125 — مكتبة فيديوهات خاصة

تم استبدال بوابة **المتصفح/يوتيوب** في الشاشة الرئيسية ببوابة **📚 مكتبتي**، مع أقل تغيير ممكن على المشغّل الحالي.

## التطبيق
- `PrivateLibraryActivity.kt`: واجهة RTL داكنة قريبة من الشكل المرفق.
- Home: بانر، كاروسيل 4 ثوانٍ، نقاط صفراء، «حلقات جديدة»، «آخر الأعمال المضافة».
- بحث + تفاصيل + قائمة حلقات.
- صور عبر Glide.
- Skeleton + إعادة المحاولة.
- Token محفوظ بتشفير AES/GCM داخل Android Keystore.
- عند اختيار حلقة يتم طلب `/api/play/:videoId` ثم فتح `PlayerActivity` الحالي بنفس `url/ref/ua/title`، بدون مشغّل جديد.
- لا يوجد أي تعديل على محرك الترجمة نفسه.

### مهم قبل البناء
افتح:
`app/src/main/java/com/tttt/subtitler/PrivateLibraryActivity.kt`
وغيّر:
`PrivateApi.BASE`
إلى دومين السيرفر الحقيقي، مثل `https://media.example.com`.

## السيرفر
داخل `server/`:
- Node.js + Express + SQLite.
- رفع MP4.
- تحويل HLS تلقائيًا بواسطة ffmpeg.
- JWT + rate limit + CORS + Helmet.
- روابط تشغيل موقعة ومؤقتة؛ الـm3u8 يعيد كتابة روابط الشرائح الموقعة بدل كشف مسار التخزين.
- يدعم local storage للتجربة وS3/R2 عبر إعدادات S3-compatible.
- لوحة `/admin`.

## محتوى MWitcher القديم
تم فحص الـAPK المرفوع `Anime_Witcher v1.4.7`. التطبيق لا يحمل كتالوج الحلقات كاملًا كقاعدة بيانات ثابتة داخل APK؛ بيانات المكتبة تُجلب وقت التشغيل. لذلك لا يوجد ملف واحد داخل الـAPK يمكن نسخه ليعطي كل الأعمال والحلقات القديمة. وضعت فقط `server/old_witcher_visible_catalog.json` للعناوين المقروءة من الصورة المرفقة، بدون اختلاق قائمة كاملة.

لو كانت بيانات الفيديوهات المملوكة لك موجودة في تصدير JSON/DB من المصدر القديم، يمكن إدخالها مباشرة في نفس الجداول دون تغيير التطبيق.
